# 0.8.0 发布验证

验证环境：Apple M4 Pro，macOS 26.6.2。其他设备和首次下载后的系统拦截体验尚待独立验证，因此当前标记为公开测试版。

## 已验证

- 全新源码副本能校验并安装固定运行时；重复安装和错误 SHA-256 拒绝通过验证。
- 常规 Swift 测试无失败；16 个 GPU 集成测试默认跳过，本次更新未修改密码计算引擎。
- 打包应用通过 `codesign --verify --deep --strict`，可正常启动。
- 自动更新开关跨重启保留；未检查、更新失败、已是最新状态在原生界面显示正确。
- 使用应用内 Ed25519 公钥独立验证真实安装包和 appcast；对安装包或清单作等长篡改均被拒绝。
- 从真实 GitHub 更新源自动发现 build 20、后台下载并准备更新；退出 build 19 后由 Sparkle 替换应用，无需手动复制。此次验证仅将旧构建的检查时间重置以触发到期检查，未更改更新周期。
- 更新后的可执行文件及 Info.plist 与发布构建完全一致，严格签名校验通过；访达扩展保持启用。重新启动并检查更新显示“已是最新”。

## 正式发布前仍需验证

- Developer ID 签名、公证，以及另一台 Mac 从浏览器下载后的首次安装。
- 下载中断、断网恢复、磁盘不足、安装权限不足及运行任务期间的更新行为。
- 不同容量、固实压缩、加密与分卷档案的真实样本，以及临时文件被外部应用修改后的保存体验。

密码恢复 GPU 集成测试的命令见 README。发布步骤及公钥验签方法见 RELEASING.md。
