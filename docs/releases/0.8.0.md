# 轻压 0.8.0

首个公开开源版本，适用于 Apple Silicon Mac、macOS 26 及以上系统。

- 原生压缩包浏览，按需解压、空格预览、双击打开文件。
- ZIP / 7Z 压缩与常见格式解压，访达右键操作、默认打开应用设置。
- 内置简单密码找回、字典与规则、GPU 加速。
- 新增 Sparkle 自动更新：默认每天检查，后台下载并验签，退出时自动替换。可在设置中关闭或手动检查。
- 应用原创代码与图标采用 MIT 许可；附第三方许可证及所需对应源码。

下载 `LightZip-0.8.0-arm64.zip`，解压后将轻压放入“应用程序”。开发者构建需要的第三方运行时为 `LightZip-runtime-0.8.0-arm64.tar.gz`，普通用户无需另行下载。

此版本使用本地代码签名，**尚未通过 Apple Developer ID 公证**，首次启动可能出现系统拦截。请确认下载来源后遵循 macOS“隐私与安全性”的提示，无需关闭系统安全保护。更新包与更新清单均已使用 Ed25519 签名。
